    番外篇：发挥实习的最大价值

    2026 五月

    作者今年毕业了，并且如愿以偿加入了一个规模和文化都比较符合我的公司。我的朋友推荐我添加一个章节，来聊一聊我大学时期作为实习生，是如何最大化自己在一份实习中的收获的。

    除了降低求职难度外，实习无非就三个主要目的：

    • 学习技术
    • 增加人脉
    • 体验一家公司/一个组的文化

    下面展开说一下，顺便聊聊我每份实习的收获。

    技术

    这里所说的“技术”很宽泛，不单指常规的技术栈。在大公司里，你有机会接触到一些个人小项目中通常用不到的工具，比如：

    • 开发环境（dev）、预发布环境（staging）、生产环境（prod）
    • 分布式部署（如 k8s）
    • 分布式数据处理（如 Hadoop、Spark）
    • Telemetry、Prometheus
    • 等等

    像使用 Web 开发栈做生产工程这类标准化技能，学起来相对容易，不同实习之间差异也不大。但上面这些工具，靠自己是很难接触到的，非常值得在实习期间去学。你不仅能在使用它们的过程中提升能力，为下一次求职积累额外优势，还可能发现一些之前不了解的岗位方向，比如 infra、platform 组。

    想学的同学不用等 mentor 安排。入职后先问清楚团队在用哪些内部工具，然后主动认领一个小任务（比如加一个监控指标、写一个数据 pipeline 的小脚本）。边做边问，比旁听学得快得多。

    另外，值得主动去学的还有工程流程本身：代码评审的标准、设计文档怎么写、线上事故如何处理、跨团队协作的节奏。这些东西不依赖具体技术栈，但能让你变成一个更好的工程师，下一份实习也能更快上手。

    人脉

    人脉这个词听起来很硬核，但其实只是让你和周围的人建立一些轻松的关系。

    实习的一个很大价值，是把你放到一堆聪明人中间一起共事。这些人是你的同事，也可以是你的资源。

    没有人不喜欢跟聪明人共事。如果你能向同事、mentor、manager 展示你的业务能力和学习能力，这不仅能影响 return offer，还能让他们以后为你内推其他岗位。

    一些你可以做的事：

    • 和组里的同事 coffee chat，了解他们负责了什么模块，适当向有意思的方向提问
    • 和公司里的其他同事也约 coffee chat，比如其他组的技术负责人、skip level manager、principal engineer 等。问问他们最近遇到的有意思的技术难点，或者有什么建议可以给你

    我个人觉得程序员总体是对聊技术比较开放的群体，我以前的 coffee chat 一般也都很顺利。只要你展现出优秀的能力，这些人都会变成你的人脉。不用刻意维系什么，保持专业、真诚就行。以后你找人内推的时候，对方记得你是个靠谱且聪明的人，这就够了。

    文化

    最后聊一个实习里给我价值很大的东西：观察一个公司或一个组的文化。

    我以前也像很多人一样很向往大厂，但在亚马逊和微软实习完后，我发现我其实更喜欢小一点的工程部门。

    实习期间可以尽力去观察：

    • 大家的交流模式（开会准时吗？敢不敢说“不知道”？）
    • 办事效率（一个需求要走多久？有没有无意义的流程？）
    • 内部工具好不好用
    • 出故障了是先甩锅还是一起修？
    • 文档写得好不好？代码审核是走形式还是真在抠细节？

    记下你喜欢和不喜欢的东西，方便实习后做总结。这些东西会直接影响你每天开不开心、能不能学到东西。

    另外也建议每次实习都选一个环境不太一样的地方：大厂去过了，下次就去小厂或创业公司看看。

    你只有亲身体验过不同文化，才知道自己真正适合什么。
